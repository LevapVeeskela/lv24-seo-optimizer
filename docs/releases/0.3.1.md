# 0.3.1 — npm README parity

Documentation-only patch. `0.3.0` shipped the features; this release brings the npm package page
in line with the repository README and keeps all three channels on the same version.

## Changed

- `packages/npm/README.md` now documents the 0.3.x surface: 11 MCP tools (including
  `seo_report_diff`), week-over-week `report diff`, sitemap ↔ crawl coverage diff, honest
  `complete`/`total`/`limitations` semantics, plus banner, badges and current usage examples.
- Root README (EN/RU), `docs/releases.md` and the version metadata agree on `0.3.1`.

## Not changed

- No code, schema, CLI command, MCP tool signature, output field or exit code changed.
- No database migration. Snapshots and delivery ledgers from `0.3.0` are used as is.
- Operational limits are unchanged: serial crawler, serial MCP tool calls on the loop thread,
  process-local limiting, at-least-once delivery.

See [CHANGELOG](../../CHANGELOG.md) and [0.3.0 notes](0.3.0.md).
